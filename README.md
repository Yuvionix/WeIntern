# WeIntern - Week 1: Interactive To-Do List

## Description

A simple, interactive to-do list web application built with HTML, CSS, and JavaScript. This project demonstrates basic front-end development skills including DOM manipulation, event handling, and responsive design.

## Features

- ✅ **Add Tasks**: Enter a task in the input field and click "Add" to create a new to-do item
- ✅ **Mark as Complete**: Click the checkmark (✔) button to toggle task completion with visual feedback
- ✅ **Delete Tasks**: Click the cross (✖) button to remove tasks from the list
- ✅ **Input Validation**: Empty tasks are rejected with visual error indication
- ✅ **Responsive Design**: Clean, modern UI with smooth animations and gradients
- ✅ **Real-time Updates**: Instant visual feedback for all user interactions

## How to Run

### Option 1: Direct File Opening
1. Clone or download this repository
2. Navigate to the `Week 1` folder
3. Open `index.html` in your web browser

### Option 2: Local Server (Recommended)
1. Clone or download this repository
2. Navigate to the `Week 1` folder
3. Start a local HTTP server:

```bash
python3 -m http.server 8000
```

4. Open your browser and go to `http://localhost:8000`
